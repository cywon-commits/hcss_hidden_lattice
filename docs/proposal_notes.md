## 요약

**질문: 2차원 입자계가 결정에서 액체나 비정질로 바뀔 때, 입자 Voronoi 그물 위의 반강자성 Ising 좌절 fr과 세 번째 상태(비용 D3)의 배치는 disclination 구조를 어떻게 반영하는가?**

입자 i의 배위수를 zᵢ, disclination 전하를 qᵢ = 6 − zᵢ라 하면, Voronoi 그물의 홀수 면은 정확히 홀수 전하 disclination입니다. 따라서 Ising 좌절은 disclination 전하의 Z₂ 사영이고, fr은 이들을 짝짓는 최소 끈 길이(Delaunay 위의 최소 T-join)입니다. 열 배치의 Voronoi 그물은 항상 차수 3이므로, D3 논문의 healing 정리가 모든 상에서 적용됩니다. 0 < D3 < 1의 바닥상태는 세 번째 상태 사이트를 정확히 fr개 쓰고, 각 사이트가 끈 하나를 끊습니다.

이미 확립된 해석 결과가 둘 있습니다. 첫째, 정사각–삼각 타일링에서 홀수 배위 입자 비율은 조성만의 함수이고 phason 뒤집기에 불변입니다(12회 이상 비율에서 4√3 − 6 ≈ 0.93). 둘째, 정사각형 Delaunay 면의 대각선 선택이 숨은 Z₂ 자유도로서 셀 홀짝성을 바꿉니다. 열 요동은 정사각 상에서 fr을 늘리지만 준결정에서는 오히려 줄입니다.

연구는 두 갈래로 진행합니다. hard-disk 융해에서 fr의 과잉량(fr − n\_odd/2)이 hexatic 구간에서 기존 지표(n\_odd, ψ₆)를 넘는 신호를 주는지 시험하고, 숄더 퍼텐셜 계에서는 기준 질서(육각, 정사각, λ\* 타일링, 정사각–삼각 준결정)에 따라 "결함"과 "좌절"이 어떻게 재정의되는지, 특히 대각선 Z₂가 열평형에서 어떻게 정렬되는지를 봅니다. 기존 숄더 타일링 연구(저장소 cywon-commits/hardcore\_square\_shoulder, hcss\_lambda\_star)와 직접 이어집니다.

## 이론적 배경

**모형.** 입자 배치의 Voronoi 그물 G를 격자로 쓰고, 그 위에 D3 모형을 놓습니다. 면은 입자 하나의 Voronoi 셀이고, 일반적 위치에서 꼭짓점은 모두 차수 3입니다.

```latex
E(s)=\#\{uv\in E: s_u=s_v\}+D_3\,\#\{v: s_v=3\}
```

**1. 좌절 = disclination의 Z₂ 사영.** zᵢ각형 셀이 홀수 면이고, 홀수 면이 Ising 좌절 중심입니다.

```latex
\text{odd face } i \iff z_i \text{ odd} \iff q_i = 6 - z_i \text{ odd}
```

홀수 셀의 개수는 악수 보조정리(Delaunay 차수 합 = 2E)에 의해 항상 짝수입니다. 평면 영역에서 fr은 홀수 셀들을 Delaunay 결합으로 잇는 최소 T-join이고, 최소 가중 완전 매칭으로 정확히 구합니다. 이것은 D3 논문 Sec. VII의 truncation 구성과 같은 구조이며, 입자의 Delaunay 삼각분할이 모 타일링입니다.

**2. 차수 4 꼭짓점은 측도 0.** 정사각형 Delaunay 면은 이상화된 배치에서만 생깁니다. 열 배치는 일반적 위치에 있으므로 Voronoi 그물은 항상 Δ = 3이고, 정사각형은 두 대각선 중 하나로 잘린 삼각형 쌍으로 나타납니다. 따라서 퇴화는 계산 복잡도 문제가 아니라, 정사각형마다 붙는 대각선 Z₂ 변수의 문제입니다(다음 절).

**3. 주기 경계의 호몰로지 보정.** 토러스 위에서는 홀수 면만이 아니라 홀수 길이의 비수축 고리도 끊어야 합니다. 따라서 fr은 Z₂ 호몰로지 네 부류 각각에서 구한 T-join의 최소입니다.

```latex
\mathrm{fr} = \min_{h\in H_1(T^2;\mathbb Z_2)} \mathrm{Tjoin}_h(\text{odd faces})
```

healing 정리(Theorem 8)가 평면성을 가정하는지 확인하고, 토러스에서 성립하지 않으면 열린 경계(또는 큰 계의 내부 창)로 측정합니다. 예비 결과의 ℓ̄ ≈ 1.07은 이 보정을 넣어 다시 계산합니다.

**4. Healing.** Δ = 3인 평면 그래프이므로 D3 논문 Theorem 8에 의해 다음이 성립합니다.

```latex
E_0(D_3)=\min(D_3,1)\,\mathrm{fr}
```

0 < D3 < 1에서 세 번째 상태 사이트는 정확히 fr개이고, 각각 좌절 끈 하나를 끊습니다. Corollary 16의 구성 절차로 바닥상태 자체를 다항시간에 얻으며, 이는 모든 열 배치에 적용됩니다.

**5. 관측량.**

| 기호 | 정의 | 의미 |
| --- | --- | --- |
| n\_odd / N | 홀수 배위 입자 비율 | 홀수 disclination 밀도 |
| fr / N | 입자당 Ising 좌절 = 입자당 세 번째 상태 수 | 좌절의 총량 |
| Δfr = fr − n\_odd/2 | 과잉 좌절 (≥ 0) | 이웃끼리 짝지어지지 못한 결함의 양. 주 관측량 |
| ℓ̄ = fr / (n\_odd/2) | 평균 끈 길이 (≥ 1) | 1이면 모두 이웃 짝(전위형) |
| P(ℓ) | T-join의 개별 끈 길이 분포 | 묶인 쌍과 자유 결함의 구분 |
| 대각선 상관 | 정사각형 대각선 Z₂ 변수의 상관 (정사각·준결정 상) | 숨은 정렬 자유도 |
| 세 번째 상태 사이트의 공간 상관 | healing 사이트의 g(r), ψ₆와의 교차상관 | 결함 구조의 실공간 지도 |

**6. 예비 결과 (주기 삼각 격자 + 가우스 잡음 σ, 576셀, 호몰로지 보정 전).** σ ≲ 0.10에서는 T1 문턱 때문에 홀수 셀이 0입니다. σ ≈ 0.15에서 홀수 셀 9%, ℓ̄ = 1.00이고, σ ≳ 0.3에서는 Poisson 값(6각 셀 약 0.30, 홀수 셀 약 0.50)에 포화되며 ℓ̄ ≈ 1.07입니다. 무작위 잡음에서는 결함이 거의 모두 이웃 짝으로 나타났습니다.

## 확립된 해석 결과

정사각–삼각 타일링에서 홀수 배위 비율은 조성 x = N\_t/N\_s만으로 정해지고, 정사각형 대각선 선택이 이를 절반으로 줄이거나 0으로 없앨 수 있습니다. 아래는 원본 1단계의 결과입니다.

**1. 조성 공식.** Delaunay를 정사각형 N\_s개와 정삼각형 N\_t개의 타일링으로 두고, 4⁴ 꼭짓점은 없다고 합니다. 그러면 꼭짓점은 3⁶(차수 6)이거나 5-타일 꼭짓점(3².4.3.4, 3³.4², 차수 5)이며, 5-타일 꼭짓점은 모두 정사각형 2개와 삼각형 3개를 가집니다. 모서리를 세면 다음을 얻습니다.

```latex
4N_s = 2n_5,\qquad 3N_t = 6n_6 + 3n_5
\;\Rightarrow\; n_5 = 2N_s,\quad n_6 = \tfrac{N_t}{2}-N_s,\quad N=\tfrac{N_t}{2}+N_s
```

```latex
\frac{n_\text{odd}}{N} = \frac{2}{1+x/2},\qquad x=\frac{N_t}{N_s}
```

- **phason 불변성.** 뒤집기는 타일 수를 보존하므로 n\_odd는 정확히 불변입니다. 원본의 질문 "phason 뒤집기에 대해 fr은 불변인가"는 n\_odd 수준에서 해결됩니다.
- **12회 이상 비율.** 개수 비 N\_t : N\_s = 4 : √3을 넣으면 다음과 같습니다.

```latex
\frac{n_\text{odd}}{N} = 4\sqrt3-6 \approx 0.928,\qquad \frac{n_6}{N} = (2-\sqrt3)^2 \approx 0.072,\qquad \frac{\mathrm{fr}}{N} \ge 2\sqrt3-3 \approx 0.464
```

- **극한.** 육각 상(x → ∞)에서 0, σ상(x = 2)에서 1입니다.
- **자명화.** 정사각형의 네 꼭짓점이 모두 홀수이므로, 홀수 꼭짓점들은 타일 모서리로 완전 매칭됩니다(12회 패치에서 내부 홀수 꼭짓점 3582개 전부 매칭, 일반 증명은 아직). 따라서 완벽한 상에서 fr = n\_odd/2, ℓ̄ = 1입니다.

**2. 대각선 Z₂.** 열 배치에서 정사각형은 대각선 하나로 잘립니다. 대각선의 두 끝점은 차수가 하나씩 늘고, 나머지 두 꼭짓점은 그대로입니다. 꼭짓점 i를 지나는 대각선 수를 kᵢ라 하면 다음과 같습니다.

| 상 | 꼭짓점이 속한 정사각형 수 | 차수 | 대각선 무작위일 때 홀수 비율 | 대각선 정렬 시 |
| --- | --- | --- | --- | --- |
| 정사각 (4⁴) | 4 | 4 + kᵢ, kᵢ ∈ {0,…,4} | 1/2 (이상 상태 0에서 증가) | 모두 같은 방향이면 모두 6, fr = 0 |
| 정사각–삼각 12회 | 2 (5-타일 꼭짓점) | 5 + kᵢ, kᵢ ∈ {0,1,2} | n\_odd/N = 2√3 − 3 ≈ 0.46 (0.93에서 감소) | 정확 덮개가 있으면 모두 6, fr = 0 |
| 육각 (3⁶) | 0 | 6 | 0 | 0 |

**3. 정리: 정확 대각선 덮개는 항상 존재하고 유일하다.** 5-타일 꼭짓점은 정확히 정사각형 2개에 속하므로, 정사각형을 꼭짓점으로, 5-타일 꼭짓점을 모서리로 하는 그래프 Q를 만들 수 있습니다. 정사각형 s의 꼭짓점에 체스판 부호 c\_s(v) = ±1(마주 보는 꼭짓점은 같고 이웃한 꼭짓점은 다름)을 주면, 대각선 σ\_s가 v를 지나는 조건은 σ\_s = c\_s(v)이고, "정확히 하나"라는 조건은 Q 위의 Ising 결합이 됩니다.

```latex
\sigma_s\sigma_t = J_v \equiv -\,c_s(v)\,c_t(v),\qquad n_\text{odd}(\sigma) = \#\{v:\sigma_s\sigma_t\neq J_v\}
```

Q의 고리에서 J의 곱은 게이지 불변이며, 고리가 정사각형을 마주 보는 꼭짓점으로 곧게 통과하는 횟수 b로 정해집니다.

```latex
\prod_{\text{cycle}} J_v = (-1)^{b}
```

Q의 면 하나가 둘러싸는 영역 R은 삼각형만 포함합니다. 경계 정사각형 s가 R 쪽으로 내놓는 변의 수를 e\_s라 하면(곧게 통과 ⇔ e\_s = 2), 내각은 5-타일 꼭짓점에서 60°·m\_v, 정사각형 안쪽 모서리에서 270°입니다. 내각 합 공식에 넣으면 다음을 얻습니다.

```latex
2\sum_v m_v + 3\sum_s (e_s-1) = 6L-12 \;\Rightarrow\; b\equiv\sum_s(e_s-1)\equiv 0 \pmod 2
```

따라서 모든 면에서 J의 곱은 +1이고, 평면에서 J는 좌절되지 않습니다. 삼각형은 30°의 짝수 배만, 정사각형은 홀수 배를 기여한다는 각도 홀짝성이 핵심이며, 조성이나 12회 대칭은 쓰이지 않습니다. 무작위 정사각–삼각 타일링에도 성립합니다.

- **숨은 삼각 격자.** 모든 정사각–삼각 타일링은 정사각형마다 대각선 하나를 골라 모든 꼭짓점이 6배위인 삼각분할로 바꿀 수 있고, 그 선택은 Q의 연결 성분마다 정확히 2가지(서로 반대쪽 대각선 집합)입니다. 덮개의 대각선은 5-타일 꼭짓점의 완전 매칭이므로, 정사각–삼각 타일링은 "삼각 격자에서 완전 매칭 모양의 모서리 집합을 지운 것"과 같습니다. 문헌에 이미 있는지는 확인이 필요합니다.
- **숨은 강자성체.** 덮개 g로 게이지를 바꾸면(τ\_s = σ\_s g\_s) n\_odd는 Q 위 강자성 Ising의 자구벽 길이입니다. 덮개에서 0, 무작위 대각선에서 n\_odd/N = 2√3 − 3 ≈ 0.46입니다. 홀수 셀은 닫힌 자구벽 위에 이웃끼리 놓이므로 fr = n\_odd/2가 자연스럽게 따라옵니다.
- **토러스에서도 좌절 없음.** 비수축 고리에서도 같은 각도 논증이 성립합니다. 고리 한쪽 경계의 닫힌 다각형은 평평한 토러스에서 회전수가 0이므로, 내각 합 식의 상수항만 −12에서 0으로 바뀌고 홀짝성은 같습니다. 따라서 주기 근사체에서도 홀로노미는 항상 +1이고, 정확 덮개가 주기를 유지한 채 존재합니다. 원본이 걱정한 "계를 가로지르는 강제 자구벽"은 생기지 않습니다.

3³.4² 상은 Q가 정사각형 줄마다 끊어져 있어, 덮개의 축퇴가 줄 수만큼(2^줄 수) 커집니다. 이것이 Q가 연결되지 않는 유일한 경우였습니다. 코드는 sqtri.py(팽창, 면 구성, Q와 덮개)입니다.

**4. 대각선 결합의 부호: 덮개는 기계적 메커니즘이다.** 정사각형을 rhombus로 찌그러뜨리되 모든 변 길이와 삼각형은 그대로 둔다고 합시다. 덮개 대각선의 끝점(짧아지는 대각선)은 각이 90° + θ, 나머지 두 꼭짓점은 90° − θ가 됩니다. 5-타일 꼭짓점이 정확히 한 번 덮이면 각 합이 그대로 유지됩니다.

```latex
(90^\circ+\theta)+(90^\circ-\theta)+3\times 60^\circ = 360^\circ
```

즉 **정확 덮개 조건은 "모든 꼭짓점이 평평한 채로 정사각형을 균일하게 기울이는 변형"이 존재할 조건과 같습니다.** 따라서 유효 결합의 부호는 모형과 무관하게 J이고(게이지 강자성), 그 세기는 접촉 그물이 대각선에 얼마나 국소 강성을 주는지로 정해집니다.

| 단계 | 내용 | 결과 |
| --- | --- | --- |
| 유한 변형 | 덮개를 따라 θ = 0–75°로 기울여 펼침 | 패치(최대 약 3.5만 타일)에서 반올림 오차 수준으로 닫힘. 무작위 대각선은 오차 약 40으로 닫히지 않음 |
| 영 모드 | 타일 변에만 용수철을 둔 조화 그물의 고윳값 | 영 고윳값 4개 = 강체 운동 3 + 메커니즘 1. 메커니즘은 게이지에서 정확히 균일한 기울임 |
| 결합 부호 | 이웃 정사각형 기울임 상관 ρ의 부호를 J와 비교 | 958개 Q 모서리 모두 sign ρ = J. 변 용수철만 있으면 ρJ ≈ 0.998(대각선이 하나의 모드에 종속) |
| 국소 강성 k\_d | 대각선 용수철 k\_d 추가 | 상관은 모든 거리에서 J 부호를 유지하며 지수적으로 감소. 상관 길이는 k\_d가 작을수록 길어짐(대략 k\_d^(−1/2)) |

**결과.** 접촉 극한(타일 변만 구속)에서는 모든 대각선이 하나의 영 모드에 묶여 있으므로, 열 요동 속에서도 게이지 자화는 거의 완전히 정렬됩니다. 그러면 준결정의 Voronoi 그물은 대부분의 시간 동안 **모든 셀이 6각형인 숨은 삼각 위상**이고, n\_odd는 0.93(이상 타일링)도 0.46(무작위 대각선)도 아닌 0 근처입니다. 대각선을 국소적으로 붙잡는 강성(대각선 방향 숄더 상호작용 등. 압력은 아래 6번처럼 오히려 기울임을 선호함)이 있으면 상관 길이 ξ가 유한해지고, 홀수 셀은 길이 ξ 정도의 자구 사이 벽에만 남습니다. 이때 n\_odd/N은 대략 1/ξ에 비례합니다.

**5. 메커니즘의 경로와 λ\*.** 같은 메커니즘을 계속 기울이면 다음 상태들을 차례로 지납니다(타일 변 길이를 a라 하면 짧은 대각선 = 2a sin((90° − θ)/2)).

| θ | 정사각형 → | 짧은 대각선 | 전체 모양 |
| --- | --- | --- | --- |
| 0° | 정사각형 | √2 a | 정사각–삼각 타일링 |
| 30° | 60°/120° 마름모 = 삼각형 둘 | a | 삼각 격자(간격 a) |
| 60° | 30°/150° 마름모 | 2a sin15° | 정삼각형–30° 마름모 타일링, 모서리 방향 12개 |

60°에서 타일 변을 숄더 거리 a = λ\* = 2cos15°로 두면 짧은 대각선은 2λ\* sin15° = 2 sin30° = 1, 즉 정확히 코어 접촉입니다. 국소적으로는 λ\*의 30° 마름모가 "정사각형을 기울이는 경로의 끝"입니다. 그러나 **타일링 수준에서 λ\* 타일링은 정사각–삼각 타일링의 메커니즘 상이 아닙니다.** 저장소의 주기 근사체(sim/approx2\_sym.npz, 입자 1590개)로 확인한 결과는 다음과 같습니다.

- 입자 Delaunay는 정삼각형(변 λ\*) 1164개와 (1, λ\*, λ\*) 이등변 삼각형 2016개, 즉 30° 마름모 1008개로 나뉩니다. 조성은 N\_t/N\_R = 2/√3이고, 12회 정사각–삼각 타일링의 상(4/√3)의 절반입니다.
- 마름모를 정사각형 쪽으로 되돌리면 꼭짓점의 각 합이 60° × (예각 수 − 둔각 수)만큼 바뀝니다. 되돌릴 수 있는 꼭짓점은 예각과 둔각 수가 같은 유형뿐이며, 근사체 꼭짓점의 50%입니다. 내역은 (삼각형 3, 예각 1, 둔각 1) 35%, (0, 2, 2) 11%, 3⁶ 3%입니다. 나머지는 되돌릴 수 없고, 그중 가장 많은 것은 (삼각형 1, 둔각 2) 28%입니다.

따라서 λ\* 앙상블은 메커니즘 상보다 훨씬 크며, 둔각 두 개가 만나는 꼭짓점처럼 정사각–삼각 타일링에서 오지 않는 국소 배치가 핵심을 이룹니다. 되돌릴 수 있는 꼭짓점들이 이루는 영역이 "기울어진 정사각–삼각(–정사각) 영역"으로서 의미가 있는지는 별도 질문으로 남깁니다.

**6. HCSS에서 메커니즘의 유효 퍼텐셜 V(θ).** 타일 변이 구속되는 경우는 코어 접촉(a = 1)과 숄더 경계(a = λ) 두 가지입니다. 12회 패치에서 θ = 0–60°의 모든 입자 쌍 거리를 계산한 결과, θ < 30° 구간에서 거리 1, √2, √3을 가로지르는 쌍은 **정사각형의 두 대각선뿐**입니다. 따라서 λ < √3에서 정사각형 하나의 에너지는 다음 두 항만으로 정해지고(패치에서 계단 위치까지 정확히 확인), 넓이는 a² cos θ로 줄어듭니다.

```latex
d_s=2a\sin\!\left(45^\circ-\tfrac{\theta}{2}\right),\quad d_l=2a\cos\!\left(45^\circ-\tfrac{\theta}{2}\right),\qquad h(\theta)=\varepsilon\,\big([d_s<\lambda]+[d_l<\lambda]\big)+P\,a^2\cos\theta
```

압력 항은 θ에 대해 위로 볼록하므로 **압력은 언제나 기울임을 선호**합니다. 무엇이 기울임을 막는지는 λ에 따라 셋으로 갈립니다.

| 경우 | 대각선 문턱 | V(θ) | T = 0의 결과 |
| --- | --- | --- | --- |
| a = λ (변이 숄더 경계) | θ < 30°에서 숄더 안으로 들어오는 쌍 없음 | 0 \~ 30° 평평 | 압력이 곧바로 θ = 30°(간격 λ 삼각 격자)로 밀어냄. 정사각형은 T = 0에서 안정하지 않음 |
| a = 1, λ > √2 | 긴 대각선이 θ\_l = 90° − 2 arccos(λ/2)에서 숄더 밖으로 나감 | 에너지 −ε 계단 | 에너지와 압력이 모두 기울임을 선호 → 코어 삼각 격자로 붕괴 |
| a = 1, λ < √2 | 짧은 대각선이 θ\_s = 90° − 2 arcsin(λ/2)에서 숄더 안으로 들어옴 | \|θ\| < θ\_s 평평, 밖에서 +ε 벽 | 압력이 벽 ±θ\_s로 밀어붙임 → **정사각형마다 부호만 남는 Ising 변수**, J로 결합 |

마지막 경우가 정사각–삼각 상이 실제로 존재할 수 있는 영역입니다. 결과를 정리하면 다음과 같습니다.

- **숨은 Ising.** T = 0의 바닥상태는 덮개를 따라 균일하게 ±θ\_s만큼 기운 타일링 두 개입니다(Q 성분마다). 덮개 대각선 방향이 세 개(Stampfli 패치에서 45°, 105°, 165°)뿐이므로, 질서상은 12회 대칭을 6회로 깹니다. 유한 온도에서 부호가 무질서해지면 정사각형은 평균적으로 정사각형이고 12회 대칭이 회복됩니다. 즉 **12회 → 6회의 숨은 Ising 전이**가 예측됩니다.
- **우물 깊이.** 정사각형 하나당 압력 이득은 ΔV = P a²(1 − cos θ\_s) ≈ P θ\_s²/2입니다. λ = 1.40에서 θ\_s = 1.15°(ΔV ≈ 2×10⁻⁴ P), λ = 1.30에서 8.9°(0.012 P), λ = 1.20에서 16.3°(0.040 P)입니다. λ → √2이면 θ\_s → 0이므로 정사각형이 사실상 강체가 되고, 질서화 온도도 0으로 갑니다. **λ = √2는 정사각형의 대각선이 정확히 숄더 경계에 놓이는 보호 조건**입니다.
- **붕괴 압력.** 벽을 넘어 θ = 30°(코어 삼각 격자)까지 가면 넓이를 더 얻는 대신 ε를 냅니다. 따라서 P\_c = ε / (a²(cos θ\_s − √3/2)) 위에서는 정사각형이 삼각 격자로 무너집니다. λ = 1.40에서 약 7.5 ε, λ = 1.30에서 약 8.2 ε입니다.
- **a = λ 경로의 끝.** 숄더 경계 변의 경우 θ = 30°를 지나면 짧은 대각선이 숄더 안으로 들어가고(+ε), 코어 접촉 2λ sin(45° − θ/2) = 1에서 멈춥니다. λ = λ\*이면 이 끝점이 정확히 θ = 60°, 즉 λ\*의 30° 마름모입니다(5번).

**문헌 대조(확인됨).** HCSS의 정사각–삼각 12회 준결정은 숄더 바깥 반지름 δ = 1.40σ에서 나타납니다([Pattabhiraman, Gantapara, Dijkstra, J. Chem. Phys. 143, 164905 (2015)](https://dspace.library.uu.nl/bitstream/1874/322495/1/1.4934499.pdf); [Pattabhiraman, Dijkstra, J. Chem. Phys. 146, 114901 (2017)](https://dspace.library.uu.nl/bitstream/1874/348263/1/Phase.pdf)). 2015년 논문이 보고한 밀집 준결정의 값 두 개가 "변 = 코어 접촉, 대각선은 숄더 밖"인 입자 단위 정사각–삼각 타일링(조성 4/√3)에서 정확히 재현됩니다.

| 양 | 논문 | 이 계산 (a = 1, λ = 1.40) |
| --- | --- | --- |
| 입자당 에너지 U/ε | 2.536 ± 0.002 | 입자당 모서리 수 (1.5x + 2)/(x/2 + 1) = 2.536 |
| 밀집 밀도 ρ\* | 약 1.07 | 1/(입자당 넓이 0.928) = 1.077 |

따라서 6번 표의 세 번째 경우(λ = 1.40 < √2, 코어 접촉 변)가 실제 상이고, θ\_s = 1.15°입니다. 두 논문 모두 정사각형의 기울임이나 찌그러짐은 다루지 않습니다. 2015년 논문 그림 1(b)의 타일링도 입자 단위입니다. 다만 그림 1(a)의 시뮬레이션 배치(T\\\* = 0.278)에는 정사각형 2×2 덩어리(4⁴ 꼭짓점)와 오각형 결함이 섞여 있어, 4⁴ 꼭짓점이 있는 경우로 덮개 정리를 확장해야 합니다(4⁴ 꼭짓점의 평평함 조건은 네 정사각형 중 둘만 덮는 것).

**18회 준결정과의 연결(가설).** 2017년 논문은 δ = 1.27의 18회 준결정을 "변이 σ인 정삼각형과 마름모, 마름모의 대각선은 δ"로 기술합니다. 이는 정확히 6번 표 세 번째 경우에서 압력이 정사각형을 벽까지 민 모양입니다. 벽 마름모의 예각은 2 arcsin(δ/2)이고, 18회 대칭의 80° 마름모는 δ = 2 sin40° = 1.286, 즉 θ = 10°에 해당합니다(δ = 1.27이면 78.8°). 꼭짓점 (삼각형 3 + 80° + 100°)는 "정확히 한 번 덮임" 규칙과 같고, 60°·80°·100°만으로 이루어진 모서리 방향은 20°의 배수, 곧 18방향입니다. 따라서 **18회 준결정은 12회 준결정을 메커니즘으로 θ = 10°만큼 기울인 상일 가능성**이 있습니다. λ\*와 마찬가지로 18회 앙상블에 다른 꼭짓점 유형(예: 80° 세 개 + 60° 두 개)이 섞여 있는지 확인해야 합니다.

**작은 MC 확인.** 논문의 절차대로 ρ\* = 0.98에서 육각 격자를 NVT로 냉각했습니다(N = 1152, 온도당 4만 스윕, 저장소 hcss\_mc.py 엔진). 타일은 코어 결합(r < 1.12)으로 정했습니다. 냉각이 빨라 결함이 많고(결함 다각형에 닿지 않는 꼭짓점 44–47%), 한 번의 실행입니다.

|  | δ = 1.27, T\* = 0.20 | δ = 1.40, T\* = 0.278 |
| --- | --- | --- |
| 사각형 예각 | 평균 80.2°, 중앙값 79.9°, 표준편차 3.8° (벽 예측 78.8°, 18회 80°) | 중앙값 86.5° (거의 정사각형, 예측 88.9°) |
| 짧은 대각선 | 중앙값 1.315, δ보다 짧은 것 1.8% | 중앙값 1.421, δ보다 짧은 것 27% |
| 결함 없는 꼭짓점 중 "정확히 한 번" 규칙 | 80% ((3,1,1) 64%, (0,2,2) 10%, 3⁶ 6%) | 판정 불가(정사각형의 예각·둔각 구분이 잡음) |
| 규칙 밖의 평평한 꼭짓점 | (삼각형 1 + 100°×3) 9%, (삼각형 2 + 80°×3) 8% | — |

해석. δ = 1.27에서는 사각형이 스스로 약 80° 마름모가 되고, 짧은 대각선이 숄더 경계 바로 밖에 모입니다. 6번의 "압력이 벽으로 민다" 예측과 맞습니다. 18회 앙상블의 꼭짓점은 대부분 메커니즘 상과 같은 유형입니다. 하지만 규칙 밖 꼭짓점이 약 17% 있으므로, λ\*와 마찬가지로 **메커니즘 상보다 큰 앙상블**입니다. 규칙 밖 두 유형은 각각 정사각형 셋이 만나는 꼭짓점(각 합 330°)에 해당해, 기울이지 않은 상태로는 존재할 수 없습니다. 평형 비율은 더 긴 실행이 필요합니다.

**7. 일반화: 모서리 방향 족과 꼭짓점 산술.** 4⁴ 꼭짓점과 규칙 밖 꼭짓점을 한 틀에서 다루려면, 정사각형 대신 모서리 방향을 변수로 쓰는 것이 자연스럽습니다.

*(a) 정확한 배치 공간.* 변 길이 1인 삼각형과 마름모로 된 타일링의 조합을 고정합시다. 삼각형은 세 모서리를 함께 회전시키고, 마름모는 마주 보는 모서리를 평행하게 유지합니다. 이 두 관계로 모서리를 묶은 "모서리 류(class)"마다 회전각 r\_K 하나가 자유이고, 마름모의 각 변화는 φ\_s = r\_{K₁(s)} − r\_{K₂(s)}입니다. 면이 모두 닫히므로 위치는 자동으로 적분됩니다.

```latex
\dim(\text{평평한 변형 공간}) = \#\{\text{모서리 류}\} - 1
```

이 식은 선형화 없이 정확합니다(겹침이 생기기 전까지).

*(b) 족 정리(4⁴ 포함).* 정사각–삼각 타일링의 모서리 방향은 30°·m이고, 족을 m mod 2로 정합니다. 삼각형의 세 모서리는 60°씩 다르므로 한 족에 속하고, 정사각형의 이웃 모서리는 90°(= 30° × 홀수) 다르므로 족이 번갈아 바뀝니다. 따라서:

- **족 1 전체를 족 0에 대해 θ만큼 회전시키는 변형은, 꼭짓점 유형과 무관하게 모든 정사각–삼각 타일링에서 정확한 평평한 메커니즘입니다.** 4⁴ 꼭짓점에서는 각이 90+θ, 90−θ, 90+θ, 90−θ로 번갈아, 둔각 둘·예각 둘(얼음 규칙 "2-in-2-out")이 자동으로 성립합니다.
- 3번의 덮개 정리는 따름정리가 됩니다. 덮개 대각선의 끝점(둔각)은 반시계 방향으로 족 0 모서리에서 족 1 모서리로 넘어가는 모서리입니다. 고리 곱이나 토러스 홀로노미를 따로 따질 필요가 없습니다.
- 모서리 류는 각 족 안에 있으므로 2개 이상입니다. 류가 더 생기는 것은 삼각형을 한 번도 만나지 않는 정사각형 띠(리본)가 있을 때뿐입니다. 띠의 모서리가 삼각형에 닿으면 그 삼각형의 류에 합쳐지기 때문입니다. 유한한 4⁴ 덩어리는 띠가 삼각형에서 끝나므로 메커니즘을 늘리지 않습니다. 수치: 12회 Stampfli 패치 2류(5130 + 5130 모서리), σ상 2류, 3³.4² 상 13류(정사각형 줄 12 + 1), 정사각 격자 패치 44류(행 + 열).

*(c) 꼭짓점 산술.* 마름모의 예각을 90° − θ로 고정하면, 삼각형 t개, 예각 a개, 둔각 o개인 꼭짓점이 평평할 조건은 다음과 같습니다.

```latex
60t + 90(a+o) + \theta\,(o-a) = 360^\circ
```

o = a는 메커니즘 상의 꼭짓점입니다. 0° < θ < 30°에서 o ≠ a인 꼭짓점이 가능한 θ는 세 개뿐입니다.

| θ | 마름모 예각 | o ≠ a 꼭짓점 | 모(θ = 0) 각 합 |
| --- | --- | --- | --- |
| 10° | 80° | 삼각형 1 + 100°×3, 삼각형 2 + 80°×3 | 330°, 390° |
| 15° | 75° | 삼각형 1 + 75°×4 | 420° |
| 18° | 72° | 72°×5 | 450° |

MC에서 본 규칙 밖 꼭짓점은 정확히 θ = 10°의 두 유형입니다. **18회 마름모의 80°는 정사각형 셋이 만나는 꼭짓점(모 각 합 330°, 390°)이 평평해지는 유일한 기울기**이고, 가장 작은 기울기이기도 합니다. 마름모마다 예각 둘·둔각 둘이므로 Σ(o − a) = 0이고, 결함 없는 타일링에서는 두 유형의 수가 정확히 같아야 합니다. MC: 44 대 38(통계 오차 안에서 일치).

*(d) 18회 대칭은 규칙 밖 꼭짓점을 요구한다.* 80° 마름모 타일링의 모서리 방향은 20°의 배수입니다. 삼각형 모서리는 60°씩 다르므로 족을 (방향/20°) mod 3으로 정하면, 마름모는 족 f와 f ± 1을 잇습니다. 정사각–삼각 타일링을 메커니즘으로 기울인 상은 두 족만 쓰고, 20° 회전은 족을 바꾸므로 대칭은 최대 6회입니다(12회 → 6회 숨은 Ising과 같은 사실). 18회 대칭은 세 족이 똑같이 섞여야 하므로, **세 번째 족이 들어오는 규칙 밖 꼭짓점은 결함이 아니라 18회 대칭의 필요조건**입니다. MC 배치는 하나의 20° 격자에 정렬되어 있고(질서 변수 0.61), 족의 비율은 46 : 35 : 19%입니다. 두 족이 주를 이루고 세 번째 족이 섞이는 중간 상태로, 아직 18회 평형이 아닙니다.

*(e) 남은 질문.* θ = 15°(75° 마름모, 모서리 방향 24개)는 Dotera 등이 보고한 24회 준결정과 관련 있을 수 있습니다(확인 필요). λ\*(θ = 60°)도 같은 산술로 꼭짓점 유형이 정해집니다. 평형 18회 앙상블에서 규칙 밖 꼭짓점의 비율은 족 균등 조건과 꼭짓점 수 세기로 유도할 수 있을 것으로 보입니다.

**8. 18회 준결정의 Z₃ 구역 구조(정리 + MC 확인).** 7(d)의 족을 꼭짓점과 마름모 수준까지 밀고 가면, 규칙 밖 꼭짓점의 정체가 위상 결함으로 분명해집니다.

*(a) 꼭짓점 둘레의 감김.* 80° 마름모 타일링에서 꼭짓점을 한 바퀴 돌면, 삼각형 모서리(60°)에서는 족이 그대로이고, 예각(80°)에서는 +1, 둔각(100°)에서는 −1만큼 바뀝니다(mod 3). 한 바퀴의 족 감김은 w = a − o ∈ {0, ±3}이므로 꼭짓점마다 Z₃ 소용돌이 전하 q = (a − o)/3을 줄 수 있습니다.

```latex
q_v=\frac{a_v-o_v}{3}\in\{-1,0,+1\},\qquad \sum_v q_v = \frac{1}{3}\sum_{\text{rhombi}}(2-2)=0
```

삼각형 1 + 둔각 3(q = −1)과 삼각형 2 + 예각 3(q = +1)이 소용돌이·반소용돌이입니다. 7(c)의 개수 항등식 n₋ = n₊는 **전하 중성**과 같은 식입니다.

*(b) 마름모의 구역 표지.* 마름모의 두 모서리 족은 f와 f+1이므로, 마름모마다 Z₃ 표지(빠진 족 m = f+2)가 붙습니다. 꼭짓점을 지나는 족의 수로 표지의 거동이 갈립니다.

| 꼭짓점 | 지나는 족 | 둘레 마름모의 표지 | 역할 |
| --- | --- | --- | --- |
| 3⁶, (3,1,1), (0,2,2)의 a·o·a·o 배열 | 2 | 1개 | 구역 내부 |
| (0,2,2)의 a·a·o·o 배열 | 3 | 2개 | 구역 벽 |
| (1,0,3), (2,3,0) | 3 | 3개 | 벽 셋이 만나는 점 = 소용돌이 q = ∓1 |

즉 마름모 표지는 구역 안에서 일정하고, 벽(a·a·o·o 꼭짓점의 사슬)에서만 바뀌며, 벽은 소용돌이에서만 끝날 수 있습니다.

*(c) MC 확인(δ = 1.27, 빠른 냉각 배치).* 결함 없는 평평한 꼭짓점 486개 중에서, (3,1,1) 322개 중 320개, a·o·a·o 14개 전부가 표지 하나만 봅니다. a·a·o·o 38개는 전부 표지 둘(벽)이고, 소용돌이 82개(−1이 44개, +1이 38개)는 전부 표지 셋입니다. 표지 비율은 52 : 28 : 20%로, Z₃ 질서 변수는 |Σ ω^m|/N\_r = 0.29입니다(ω = e^{2πi/3}).

*(d) 대칭 해석.* 구역 하나는 정사각–삼각 타일링을 기울인 상과 같고, 대칭은 6회입니다. 세 표지는 20° 회전으로 서로 바뀝니다. 그래서 **18회 대칭 ⇔ 세 구역이 같은 비율로 섞인 Z₃ 무질서상**이고, 6회 "기울어진 정사각–삼각" 상은 Z₃ 질서상입니다. 소용돌이를 가진 3상태 Potts(시계) 모형 유형의 6회 ↔ 18회 전이가 예측됩니다. 질서 변수는 위의 Z₃ 표지 자화이고, 18회 쪽에서 규칙 밖 꼭짓점의 밀도는 벽과 소용돌이 밀도입니다.

*(e) 12회 준결정과의 대비.* 일반 기울기 θ(12회의 θ\_s = 1.15° 포함)에서는 꼭짓점 산술상 소용돌이가 없고, 표지는 기울기 부호 ±의 Z₂(숨은 Ising)로 줄어듭니다. 벽(a·a·o·o)의 모 꼭짓점은 4⁴이므로, **12회에서 Ising 구역 벽은 정사각형 띠를 따라서만 존재하고 끝날 수 없습니다.** 7(b)의 "띠가 없으면 메커니즘이 하나"와 같은 사실입니다. 정리하면, δ = 1.40은 소용돌이 없는 Z₂, δ = 1.27은 소용돌이 있는 Z₃입니다.

*(f) 규칙 밖 꼭짓점의 비율은 기하로 정해지지 않는다.* 꼭짓점 유형 다섯 개(3⁶, (3,1,1), (0,2,2), 소용돌이 ±)에 대해 세울 수 있는 식은 셋입니다. 삼각형 모서리 수, 예각 수와 둔각 수(그 차이가 전하 중성), 그리고 정규화입니다. 그래서 자유 매개변수가 둘(조성, 소용돌이 밀도) 남습니다. 18회 대칭 조건(세 족의 비율이 같음)은 Z₃ 자화가 0이라는 조건일 뿐이고, 소용돌이 밀도를 고정하지 않습니다. 따라서 규칙 밖 꼭짓점의 비율은 기하 상수가 아니라 **구역 크기, 곧 Potts 상관 길이의 척도**입니다(벽 밀도 ∝ 1/구역 크기).

*(g) 느린 냉각과 고정 온도 담금(δ = 1.27, N = 1152, NVT ρ\* = 0.98).* 결과는 표와 같습니다. M\_rh는 마름모 Z₃ 표지의 자화이고, 3족 꼭짓점은 결함 없는 평평한 꼭짓점 가운데 세 족을 지나는 것의 비율입니다.

| 실행 | 상태 | 마름모 예각 중앙값 | 3족 꼭짓점 | M\_rh |
| --- | --- | --- | --- | --- |

| 담금, B의 0.20 배치에서 | 0.20에서 20만 → 100만 스윕 | — | — | 0.35 → 0.40 (정체) |

- **마름모 각:** 모든 실행에서 80°에 고정되어 있습니다. 숄더 벽 예측대로입니다.
- **냉각 경로:** 육각 격자에서 시작하면 처음 생기는 상은 한 구역이 우세한 6회 상입니다(B의 T\* = 0.28에서 표지 73%, 삼각형도 두 족에 90%). 이는 출발한 육각 격자의 방향을 기억한 결과로 보입니다.
- **시간에 따른 변화:** 시간이 지나면서 벽과 소용돌이가 늘어 M\_rh가 줄어듭니다. T\* = 0.24에서는 100만 스윕 동안 계속 줄었고, 0.20에서는 정체했습니다.
- **해석:** 평형이 Z₃ 무질서(18회) 쪽이라는 것과 들어맞지만, 지금 자료로는 평형 상태를 판정할 수 없습니다. 구역이 섞이는 동역학이 매우 느립니다.
- **결정할 방법:** 반대 방향의 출발점(마름모 메커니즘으로 만든 단일 구역 6회 타일링 대 세 구역이 섞인 배치)에서 같은 T로 수렴시키거나, 구역 벽을 움직이는 타일 뒤집기 이동을 넣어야 합니다.

**9. Z₃ 구역 모형의 유효 이론: 벽과 소용돌이는 에너지가 0이다.**

*(a) 에너지와 넓이는 조성만의 함수.* 변이 코어 접촉(길이 1)에 있는 80° 마름모–삼각 타일링에서, 어느 평평한 꼭짓점 별(벽·소용돌이 포함)에서도 모서리가 아닌 쌍의 최소 거리는 마름모의 짧은 대각선 2 sin40° = 1.2856입니다. δ = 1.27 < 1.2856이므로 숄더 안의 쌍은 정확히 모서리뿐입니다.

```latex
E=\varepsilon\,\frac{3N_t+4N_r}{2},\qquad A=N_t\frac{\sqrt3}{4}+N_r\sin 80^\circ,\qquad H=E+PA=H(N_t,N_r)
```

엔탈피는 구역 표지, 벽, 소용돌이에 전혀 의존하지 않습니다. 즉 벽 장력 e\_w = 0, 소용돌이 중심 에너지 e\_v = 0, Potts 결합 J = 0입니다.

*(b) 결과: 엔트로피로 안정화된 무질서.* 벽의 자유에너지는 단위 길이당 σ\_w = e\_w − T s\_w = −T s\_w < 0이므로(벽이 구불구불할 수 있으면 s\_w > 0), 벽과 소용돌이는 모든 T > 0에서 늘어납니다. 따라서 이상적인 접촉 극한에서는 **6회 Z₃ 질서상이 없고, 18회 상은 12회 정사각–삼각 무작위 타일링처럼 배치 엔트로피로 안정화된 상**입니다. 8(d)에서 예측한 6회 ↔ 18회 Potts 전이는 이 극한에서는 일어나지 않는 것으로 수정합니다. 이는 8(h)의 수렴 시험(단일 구역이 녹음)과 맞습니다.

*(c) 국소 확인: 벽 꼭짓점의 비율은 순수한 조합 수.* 마름모 넷이 만나는 꼭짓점에서, 예각 둘·둔각 둘의 순환 배열은 벽형 a·a·o·o가 4가지, 내부형 a·o·a·o가 2가지입니다. 두 배열의 엔탈피가 같으면 비율은 2여야 합니다. 담금·느린 냉각 배치를 모두 모으면 672 : 348 = **1.93**입니다. 이를 자유에너지로 바꾸면 벽 꼭짓점 하나당 ΔF/T = −ln(1.93/2) ≈ 0.04 ± 0.1(배치끼리 상관이 있어 오차를 넓게 잡음)로, 0과 구별되지 않습니다.

*(d) 결합이 생길 수 있는 곳.* 에너지는 정확히 퇴화되어 있으므로, 구역 사이의 유효 결합은 모두 퇴화를 깨는 작은 효과에서 옵니다.

- **진동 자유에너지:** 꼭짓점 유형마다 자유 부피가 다르면 J\_vib ∝ T가 생깁니다. 크기는 (c)의 상한으로 제한됩니다.
- **δ와 2 sin40°의 차이:** δ가 1.2856을 넘으면 짧은 대각선에 ε가 들어가지만, 이는 마름모마다 같은 비용이라 구역 결합을 주지 않습니다.
- **결함과 밀도:** ρ\* < 1.08에서 생기는 결함 다각형이 표지별로 다르게 붙을 수 있습니다.

*(e) 12회와의 관계.* δ = 1.40에서도 같은 논리가 성립합니다(대각선 √2 > δ). 숨은 Ising 벽의 에너지도 0입니다. 다만 위상적으로 정사각형 띠를 따라서만 존재하므로, 띠가 드문 타일링에서는 부호가 사실상 고정됩니다. 그러나 θ\_s = 1.15°가 열잡음보다 작아 물리적 결과는 없습니다. 18회에서는 소용돌이가 벽을 끝낼 수 있어 벽이 자유롭게 늘어납니다.

*(f) 예측.* ① 접촉 극한의 평형에서 Z₃ 자화는 모든 T에서 M ∝ N^(−1/2)로 사라집니다. ② 벽·소용돌이 밀도와 구역 상관 길이는 온도에 거의 무관합니다(순수 엔트로피). ③ a·a·o·o : a·o·a·o = 2 : 1에서 벗어나는 정도가 진동 결합의 직접 측정입니다. ④ 규칙 밖 꼭짓점의 평형 비율은 80° 마름모–삼각 무작위 타일링의 배치 통계만으로 정해지므로, 전달 행렬로 직접 계산할 수 있습니다.

**10. Z₃ 자화는 페이존 변수다(상승된 넓이 정리).** 9(f)④을 위해 이상적인 타일 단위의 타일링 MC를 만들려고 국소 뒤집기를 찾다가, 그보다 근본적인 사실이 나왔습니다.

*(a) 국소 뒤집기 탐색.* 정수 좌표(ζ₁₈의 6차원 기저)로 모서리를 맞대어 붙인 패치를 타일 5개까지 전부 열거했습니다(2개 18, 3개 190, 4개 2187, 5개 25195). 같은 경계를 다르게 채우는 영역은 **하나도 없었습니다**. 처음에 실수 좌표로 돌렸을 때 나온 후보 212개는 반올림 때문에 같은 패치를 두 번 센 가짜였습니다.

*(b) 정리.* 타일링을 6차원으로 상승시키면, 각 타일은 ∧²Z⁶(15차원)의 2-형식 U\_i ∧ U\_j를 갖습니다. Stokes 정리에 의해 영역 안 타일들의 2-형식 합은 상승된 경계만으로 정해집니다.

```latex
\sum_{\text{tiles}} \Omega_{\text{tile}} = \oint_{\partial R} \tfrac12\, x\wedge dx \;\in\; \wedge^2\mathbb{Z}^6
```

타일의 방향 류는 삼각형 3개(족 f, 위·아래 삼각형은 같은 류)와 마름모 9개입니다. 이 12개의 2-형식은 \*\*선형 독립(계수 12)\*\*입니다. 따라서 어떤 영역이든 경계가 족별 삼각형 수와 방향별 마름모 수를 정확히 고정합니다. 마름모의 방향은 Z₃ 표지를 정하므로, **구역 조성(M\_rh, M\_tri)은 경계에 의해 고정되는 보존량**입니다. 비교하면, 12회 정사각–삼각은 7개 류가 6차원 공간(∧²Z⁴)에 있어 관계가 하나 있습니다.

*(c) 결과.*

- **상의 의미:** Z₃ 자화는 열역학적 질서 변수가 아니라 **페이존 변형의 성분**입니다. 단일 구역 6회 타일링은 최대 페이존 변형 상태이고, 18회 대칭점(페이존 변형 0)에서는 M = 0이 항등적으로 성립합니다. 9번의 "Potts 전이 없음"은 "M의 자유에너지는 페이존 탄성 F = (K/2)M²이고, K는 무작위 타일링 엔트로피에서 온다"로 더 정확히 고쳐 씁니다.
- **완화 경로:** 이상적인 타일링에서는 어떤 국소 재배치도 M을 바꾸지 못합니다. M은 경계(토러스에서는 주기 벡터의 상승) 또는 결함(페이존 전위)을 통해서만 바뀝니다. 8(h)에서 단일 구역이 녹은 것은 ρ\* = 0.98의 결함 다각형을 통한 페이존 완화이고, 남은 M ≈ 0.3과 느린 섞임은 이 경로가 느린 탓입니다.
- **뒤집기 크기:** 가장 작은 국소 뒤집기는 타일 6개 이상이며, 모든 방향 류의 수를 보존해야 합니다. 같은 방향 타일들의 위치만 바꾸는 재배치입니다.
- **9(f)④의 범위:** 규칙 밖 꼭짓점의 평형 비율은 페이존 변형 0에서 정의되는 양입니다. 국소 뒤집기가 크므로 타일 단위 MC보다는, 페이존 변형을 고정한 원통 전달 행렬(저장소 tm\_cpp의 λ\* 생성기를 개조)이 맞는 도구입니다.

**11. 삼각형과 80° 마름모만으로는 페이존 변형 0인 18회 타일링이 없다.** Z\[ζ₁₈\]의 수직 공간은 두 개(σ₅: ζ ↦ ζ⁵, σ₇: ζ ↦ ζ⁷)입니다. 18회 회전 아래 페이존 변형 성분 α₁, β₁, α₂, β₂의 각운동량은 4, 6, 6, 8로 모두 비자명하므로, 18회 대칭은 두 수직 공간의 넓이 밀도가 모두 0일 것을 요구합니다.

| 타일 | 물리 넓이 | σ₅ 넓이 | σ₇ 넓이 |
| --- | --- | --- | --- |
| 정삼각형 | +0.4330 | −0.4330 | +0.4330 |
| 80° 마름모 | +0.9848 | +0.6428 | −0.3420 |

- **두 조건이 모순:** σ₅ 넓이 0은 N\_t/N\_r = 1.4845, σ₇ 넓이 0은 N\_t/N\_r = 0.7899를 요구합니다. 같은 방법을 12회 정사각–삼각에 적용하면 알려진 4/√3이 정확히 나옵니다. 따라서 이 타일 집합의 어떤 조성에서도 페이존 변형이 0일 수 없습니다.

- **해석(가설):** σ₇ 넓이 = |α₂|² − |β₂|² > 0이면 α₂ ≠ 0이고, α₂는 각운동량 6(20° 회전에 위상 2π/3)인 Z₃ 채널입니다. 따라서 8(h)의 남은 M ≈ 0.3은 유한 크기 효과가 아니라 \*\*조성 때문에 강제된 페이존 변형(Z₃ 성분)\*\*일 가능성이 있습니다. HCSS의 δ = 1.27 "18회 준결정"은 엄밀히는 Z₃ 성분이 남은 페이존 변형 상태이거나, σ₇ 넓이가 음수인 다른 결함 타일이 있어야 진짜 18회가 됩니다.
- **검증:** 전달 행렬로 두 수직 공간의 기울기장에 대한 엔트로피 s를 계산해, 최대 엔트로피 점과 그 점의 M을 구하는 것이 의뢰서(TASK4)의 목표입니다.

**9. Z₃ 구역의 유효 이론: 벽과 소용돌이는 에너지도 부피도 들지 않는다.** 완전한 타일링(변 = 코어 접촉, 결함 다각형 없음)에서 벽 장력과 소용돌이 비용을 꼭짓점 배치로 계산하면, 두 값 모두 정확히 0입니다.

*(a) 에너지와 부피는 조성만의 함수.* δ = 1.27에서 숬더 안에 드는 쌍은 타일 변뿐입니다. 한 꼭짓점에서 변이 아닌 가장 가까운 쌍은 마름모의 짧은 대각선 2 sin40° = 1.2856 > δ이고, 어떤 꼭짓점 유형에서도 더 가까운 쌍은 생기지 않습니다. 오일러 관계 N = N\_t/2 + N\_r를 쓰면 다음과 같습니다(x = N\_t/N\_r).

```latex
\frac{E}{\varepsilon N}=\frac{\tfrac32 x+2}{\tfrac12 x+1},\qquad \frac{A}{N\ell^2}=\frac{x\,\tfrac{\sqrt3}{4}+\sin 80^\circ}{\tfrac12 x+1}
```

*(b) 벽과 소용돌이는 조성을 바꾸지 않는다.* 벽 꼭짓점(a·a·o·o)과 내부 꼭짓점(a·o·a·o)은 같은 모서리를 갖습니다. 소용돌이 쌍(삼각형 1 + 둔각 3)+(삼각형 2 + 예각 3)의 모서리(삼각형 3, 예각 3, 둔각 3)는 내부 꼭짓점 쌍 (3,1,1)+(0,2,2)와 정확히 같습니다. 따라서 조성을 고정하면 구역 구조가 무엇이든 E와 PA가 같습니다.

```latex
\sigma_{\text{wall}}^{(E+PA)}=0,\qquad \mu_{\text{vortex}}^{(E+PA)}=0
```

이는 λ\* 논문의 "조성 = 위상 전하"와 같은 구조입니다. 에너지가 조성만 보고 배열은 보지 않습니다. 12회(δ = 1.40)의 Ising 벽도 같은 이유로 비용이 0입니다.

*(c) 유효 자유에너지.* 에너지·부피 항이 사라지므로, 구역의 자유에너지에는 엔트로피만 남습니다. 배치 엔트로피(s\_w, s\_v > 0, 무질서 선호)와 진동 자유에너지 차이(κ\_w, κ\_v, 부호 미정)입니다.

```latex
\frac{F_{\text{dom}}}{k_BT}=(\kappa_w-s_w)\,L_{\text{wall}}+(\kappa_v-s_v)\,N_{\text{vortex}}
```

강체 접촉 극한에서는 진동 항도 k\_BT × (기하적 자유 부피의 로그 비)로, λ\* 잼 분석과 같은 꼴입니다. 따라서 괄호 안의 계수는 온도에 무관한 기하학적 숫자입니다.

*(d) 예측.*

- **온도로 구동되는 6회 ↔ 18회 전이는 없다.** 타일링 영역(결함 다각형이 없는 고압 쪽)에서 Z₃ 질서 여부는 κ\_w − s\_w의 부호만으로 정해지고, T와 P에 무관합니다. 전이가 있다면 조성이 바뀌거나 결함 다각형이 에너지를 들여올 때뿐입니다.
- **18회는 엔트로피로 안정화된 무작위 타일링이다.** 진동이 벽을 벌주지 않는 한(κ\_w < s\_w) 무질서가 이깁니다. 8(h)의 "단일 구역이 10만 스윕 안에 녹음"과 일치합니다. 이때 2015–2017 논문의 자유에너지 비교에서 18회 근사체가 준결정과 경쟁하는 이유는 근사체가 단일 또는 소수 구역이라는 점으로 설명됩니다.
- **규칙 밖 꼭짓점의 비율은 무작위 타일링의 통계 상수다.** 고정 조성에서 모든 삼각형–80° 마름모 타일링을 같은 무게로 세면(κ = 0) 정해지는 값이고, 진동 보정이 그것을 옮깁니다. 표본이 더 크면 평형 MC에서 측정한 25–30%를 이 값과 비교할 수 있습니다.

*(e) 시험.* 고압 NPT(타일링 밀도 근처)에서 두 온도의 G(r)과 규칙 밖 꼭짓점 비율이 같은지 봅니다. κ = 0인 무작위 타일링 열거(작은 원통 전달 행렬, λ\* 저장소의 도구를 응용)로 s\_w와 규칙 밖 비율을 구해 비교합니다.

## 가설

세 가설 중 하나라도 참이면 논문이 됩니다. H1이 거짓이고 H2·H3도 약하면, 위험 요소 절의 음의 결과로 축소합니다.

1. **H1 (전이 신호).** hard-disk 융해에서 과잉 좌절 Δfr/N = (fr − n\_odd/2)/N은 고체에서 0에 가깝고(묶인 5–7 쌍), 액체에서도 결함 밀도가 높아 작습니다. hexatic 구간에서는 자유 disclination이 드물게 떨어져 있으므로 Δfr/N, ℓ̄, P(ℓ)의 꼬리가 **밀도에 대해 비단조 극대**를 보인다. 즉 fr이 n\_odd만으로는 보이지 않는 "결함의 짝 구조"를 구분한다.
2. **H2 (대각선 정렬).** 정사각형 Delaunay 면을 가진 상에서 열 요동은 대각선 Z₂ 변수를 만든다. 정사각 상에서는 대각선이 무작위면 fr이 문턱 없이 증가하고, 정렬되면 fr = 0이 유지된다. 정사각–삼각 준결정에서는 대각선이 J 부호의 결합으로 묶여 있어(덮개 = 기계적 메커니즘), 열 요동이 n\_odd를 0.93에서 0 근처까지 줄인다. 홀수 셀은 상관 길이 ξ의 숨은 자구 벽에만 남고, n\_odd/N ∝ 1/ξ로 대각선 국소 강성을 잰다. 대각선 정렬은 정사각 → 삼각 전이의 전구 신호이다.
3. **H3 (기준 질서와 위상 보호).** Delaunay가 삼각형만으로 된 상(육각, 그리고 확인되면 λ\* 상)은 T1 문턱 때문에 낮은 온도에서 위상이 보호되어, fr이 완벽한 상의 값(육각 0, λ\* 상은 조성으로 정해지는 값)에서 문턱을 넘어야 변한다. 정사각형 면이 있는 상은 문턱이 없다. 상전이(육각 ↔ λ\* ↔ 정사각–삼각 ↔ 정사각)를 따라 fr/N의 불연속은 기준 질서의 바뀜을 반영하며, 크기는 위의 조성 공식으로 예측된다.

## 숄더 계의 상별 기준 질서와 예상

Voronoi 셀의 변 수는 입자를 둘러싼 Delaunay 면의 개수입니다. 열 배치에서는 모든 상이 Δ = 3이고, 상의 차이는 이상 셀의 홀짝성과 정사각형 면(대각선 Z₂)의 유무로 나타납니다.

| 상 | 이상 꼭짓점 배치 | 셀 변 수 | 완벽한 상의 n\_odd/N | 열 요동의 효과 |
| --- | --- | --- | --- | --- |
| 육각 | 3⁶ | 6 | 0 | T1 문턱까지 보호 |
| 정사각 | 4⁴ | 4 (+kᵢ) | 0 | 대각선 무작위면 약 1/2로 즉시 증가 |
| λ\* = 2cos15° (삼각형–30° 마름모) | 저장소 배치로 확인 필요 | 확인 필요 | 확인 필요 | 마름모가 짧은 대각선으로 잘리면 정사각형 면 없음, T1 보호 예상 |
| 정사각–삼각 12회 (다른 λ) | 3⁶, 3².4.3.4, 3³.4² | 6, 5, 5 (+kᵢ) | 4√3 − 6 ≈ 0.93 | 무작위 대각선이면 약 0.46으로 감소, 정확 덮개면 0 |
| 띠·클러스터 상 | 상에 따라 다름 | — | 계산 필요 | — |

**λ\* 상의 확인 사항.** 이 프로젝트의 λ\* 바닥상태는 정삼각형과 30° 마름모의 타일링입니다. 마름모 꼭짓점에 입자가 있다면, Delaunay는 짧은 대각선으로 마름모를 자르므로 모든 면이 삼각형이 되고 대각선 Z₂는 없습니다. 이 경우 λ\* 상의 n\_odd는 꼭짓점 차수 분포(마름모의 30°·150° 각이 모이는 방식)로 정해지며, 조성 공식과 같은 방식으로 계산할 수 있습니다. 타일 꼭짓점과 입자 위치의 관계(타일이 입자 삼각형 A, B, C의 상위 타일인지)를 저장소 배치에서 먼저 확인합니다.

**질문 목록.**

- λ\* 상의 입자 Delaunay에서 n\_odd/N은 조성만의 함수인가? phason 뒤집기에 불변인가?
- (해결) 정확 대각선 덮개는 평면과 토러스 모두에서 항상 존재하고 Q의 성분마다 2개뿐이다. 남은 것: 홀수 꼭짓점의 타일 모서리 완전 매칭의 일반 증명, 그리고 실제 숄더 상호작용이 Q 위에서 J와 같은 부호의 유효 결합을 주는가?
- 정사각 상과 준결정 상의 대각선은 열평형에서 정렬되는가? 그 정렬이 정사각 → 삼각 전이의 전구 신호인가?
- 상전이를 따라 fr/N은 조성 공식이 예측하는 만큼 불연속인가?

## 연구 단계와 판정 기준

이론을 먼저 세우고 수치는 필요한 만큼만 씁니다. 1단계는 해석과 작은 패치 계산으로 하루 안에 끝나고, 2단계가 진행 여부를 정하는 시험입니다.

1. **해석 마무리 (계산 거의 없음).**
   - λ\* 상의 입자 Delaunay를 저장소 배치로 확인하고, n\_odd/N의 조성 공식을 유도합니다.
   - 정사각–삼각 패치(Stampfli·Schlottmann 근사체)에서 홀수 꼭짓점의 완전 매칭과 정확 대각선 덮개의 존재를 확인하고, 덮개 수를 셉니다.
   - 대각선 Z₂를 게이지 형태로 정식화합니다(꼭짓점 홀짝성 = 1 + Σ 대각선 변수 mod 2).
   - *산출물: 상별 기준값 표 완성, H2의 정량 예측.*
2. **시험: hard-disk 융해.** 밀도 0.70–0.73(액체–hexatic–고체)에서 n\_odd/N, Δfr/N, ℓ̄, P(ℓ)를 ψ₆, 전위·disclination 수와 비교합니다. fr은 호몰로지 보정을 넣거나 열린 창에서 구합니다. hexatic 창은 좁아 N ≳ 10⁵이 필요하므로, 공개된 평형 배치를 먼저 찾고 없으면 event-chain MC로 생성합니다.
   - *판정: Δfr/N 또는 P(ℓ) 꼬리가 hexatic 구간에서 비단조 극대를 보이고, 그 크기 의존성이 자유 disclination 수와 맞으면 H1 채택. 모든 밀도에서 Δfr ≈ 0이면 H1 기각, H2·H3 중심으로 축소.*
3. **숄더 계 적용.** 저장소(cywon-commits/hardcore\_square\_shoulder)의 MC 배치에서 같은 관측량을 육각, λ\*, 정사각–삼각, 정사각 상과 그 사이 전이를 따라 측정합니다. 정사각형 면이 있는 상에서는 대각선 변수를 추출해 그 상관과 정확 덮개로부터의 거리를 측정합니다.
   - *판정: 완벽한 상의 값이 1단계 표와 일치하는지, H2의 정렬 또는 무질서가 보이는지, H3의 문턱 유무가 기준 질서와 맞는지.*
4. **세 번째 상태 지도.** 모든 열 배치가 Δ = 3이므로 Corollary 16으로 바닥상태를 직접 구성합니다(MILP 불필요). healing 사이트의 공간 분포를 대각선 변수, ψ₆와 비교합니다. 이상 타일링(Δ = 4)의 어려움과 열 배치(Δ = 3)의 쉬움을 대각선 변수가 잇는다는 관점에서 D3 논문의 Penrose 예와 대조합니다.
5. **확장 (선택).** 이원 혼합 2차원 유리(작은 입자는 5배위, 큰 입자는 7배위 선호)로 가서 비정질화와 fr의 관계를 봅니다. 3차원(좌절이 닫힌 선과 막)은 별도 과제로 둡니다.
